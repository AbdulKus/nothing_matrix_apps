# Glyph Lab — Nothing Phone (4a) Pro

[![Build APK and publish release](https://github.com/AbdulKus/nothing_matrix_apps/actions/workflows/build-release.yml/badge.svg)](https://github.com/AbdulKus/nothing_matrix_apps/actions/workflows/build-release.yml)

Один Android‑клиент с шестью эффектами для круглой Glyph Matrix 13×13 на Nothing Phone (4a) Pro. Эффекты можно запустить прямо из приложения, сохранить как Always‑On Glyph Toy и настраивать в интерфейсе, стилизованном под Nothing OS.

## Что внутри

- **3D‑фигуры** — куб, тетраэдр, октаэдр и пирамида; крупный выразительный каркас до внешнего кольца матрицы, контраст глубины и камерный параллакс. Автовращение независимо включается для осей X, Y и Z — можно выбрать одну ось или любую комбинацию.
- **Живой огонь** — распространение тепла, охлаждение, турбулентность и отклонение пламени акселерометром.
- **Песок** — дискретные песчинки осыпаются и накапливаются по клеткам, не отскакивают и не могут пройти сквозь круглую границу.
- **Плазма** — интерференция трёх волн с управляемой фазой и наклоном.
- **Гиперпрыжок** — объёмный звёздный тоннель со смещением точки схода.
- **Часы** — отдельный стокоподобный эффект HH/MM: пиксели времени пересчитываются раз в минуту, а при изменении автояркости физический вывод временно работает на 24 FPS.
- **Часы во время сна** — фиксированный стокоподобный формат HH/MM: при выключенном экране остаётся только время, после пробуждения возвращается выбранная анимация.
- **Автояркость** — на выбор плавно подстраивает физическую матрицу по датчику освещения или связывает её с системной яркостью экрана; отдельные ползунки задают минимум и максимум диапазона. При Flip to Glyph приложение удерживает последнее корректное lux-измерение до переворота, потому что передний датчик оказывается закрыт столом.
- Общие настройки скорости, яркости матрицы, реакции на наклон и частоты кадров. Для физических диодов применяется отдельная гамма‑компенсация, не пересвечивающая экранное превью.
- Живой экран‑превью 13×13 даже на телефоне без Glyph Matrix.

## Установка

1. Откройте раздел **Releases** и скачайте `GlyphLab-nightly.apk` либо APK из стабильного релиза.
2. Разрешите установку приложений из выбранного браузера или файлового менеджера.
3. Установите APK и откройте Glyph Lab.
4. Для интерактивного режима нажмите **«Запустить на матрице»**.
5. Для AOD нажмите **«Добавить в Always‑On Glyph Toys»** и активируйте игрушку в системном менеджере.

Phone (4a) Pro не имеет Glyph Touch и, согласно официальному GDK, поддерживает сторонние Glyph Toys только в AOD. Управление наклоном здесь берётся с обычного акселерометра телефона. Интерактивный вывод из открытого приложения использует `setAppMatrixFrame`, доступный на системных сборках от 2025‑08‑01.

Документация публичного GDK не указывает числовой диапазон яркости для `setMatrixFrame`, однако Glyph Matrix использует 12‑битные уровни яркости `0…4095`. Поэтому экранное превью остаётся в обычном 8‑битном диапазоне `0…255`, а перед отправкой на физическую матрицу значения переводятся в 12‑битный диапазон с гамма‑компенсацией. Путь Always‑On Glyph Toys в Nothing OS дополнительно приглушает сырые кадры, поэтому приложение компенсирует это только для `setMatrixFrame`; интерактивный `setAppMatrixFrame` и сами эффекты остаются без изменений.

Приложение использует актуальную конфигурацию Glyph Matrix Developer Kit: разрешение `com.nothing.ketchum.permission.ENABLE`, регистрацию Glyph Toy‑сервиса и `targetSdk 36` (Android 16). Именно начиная с этой целевой версии Nothing снимает ограничение API‑ключа. Тестовый `NothingKey` и временный ADB‑режим отладки для публичной сборки Glyph Matrix не используются.

## Сборка

Требования: Android Studio с JDK 17, Android SDK 35.

```bash
./gradlew testDebugUnitTest assembleDebug
```

Проект содержит официальный `glyph-matrix-sdk-2.0.aar`, поэтому дополнительных ручных загрузок не требуется.

GitHub Actions выпускает подписанный release‑APK, если настроены четыре секрета ниже. Пока они не добавлены, workflow безопасно сохраняет прежний debug‑APK как запасной вариант. Приватный ключ никогда не кладите в репозиторий.

### Постоянная подпись без Android Studio

`keytool` входит в JDK 17. Новый ключ можно создать из PowerShell или обычной командной строки:

```powershell
keytool -genkeypair -v -keystore glyphlab-release.p12 -storetype PKCS12 -alias glyphlab -keyalg RSA -keysize 4096 -validity 10000
```

Посмотреть алиасы и SHA‑256 fingerprint сертификата:

```powershell
keytool -list -v -keystore glyphlab-release.p12 -storetype PKCS12
```

Существующий PKCS12‑ключ от другого приложения тоже можно использовать: один ключ может подписывать несколько разных package ID. Это удобно, но связывает безопасность приложений — утечка одного общего ключа затронет их все. Для Glyph Lab важнее всего выбрать ключ один раз, сохранить несколько защищённых резервных копий и не менять его в следующих релизах. Если другое приложение использует Google Play App Signing, не путайте локальный upload key с app-signing key: для APK вне Google Play это просто выбранная вами постоянная подпись.

Закодировать keystore для GitHub Actions в PowerShell:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("$PWD\glyphlab-release.p12")) | Set-Clipboard
```

В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret** и создайте:

- `RELEASE_KEYSTORE_BASE64` — строка из буфера обмена;
- `RELEASE_KEYSTORE_PASSWORD` — пароль хранилища;
- `RELEASE_KEY_ALIAS` — alias ключа, например `glyphlab`;
- `RELEASE_KEY_PASSWORD` — пароль самого ключа.

После добавления всех четырёх секретов следующий push в `main` автоматически соберёт `assembleRelease`. Первый переход с прежнего debug‑APK требует удалить debug‑версию: у неё другой package name и временная debug‑подпись. Затем APK, подписанные одним release‑ключом, будут обновляться поверх предыдущих.

## Автосборка

- Pull request: тесты, сборка APK и Actions artifact.
- Push в `main`: тесты, устанавливаемый APK и обновление prerelease `nightly`.
- Тег `v*`: отдельный стабильный GitHub Release.

## Основа и совместимость

Приложение использует официальный [Glyph Matrix Developer Kit](https://github.com/Nothing-Developer-Programme/GlyphMatrix-Developer-Kit) и идентификатор `Glyph.DEVICE_25111p`. Целевая модель — Nothing Phone (4a) Pro с Nothing OS, Android 14 или новее.

Исходный код приложения распространяется по MIT License. Официальный Nothing SDK сохраняет собственные условия лицензирования.
